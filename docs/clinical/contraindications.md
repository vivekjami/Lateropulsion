# Contraindication screen and stop rules (in-app wording keys)

Screened before **every** session; any positive answer blocks the session (`ContraindicationChecklist`).

| Key | Item |
|---|---|
| ci_seizure | Uncontrolled seizure disorder or photosensitive epilepsy |
| ci_visual | Severe visual impairment or diplopia the headset cannot accommodate |
| ci_vestibular | Acute vestibular crisis with intractable vomiting |
| ci_cardiovascular | Unstable cardiovascular status |
| ci_facial | Open facial wound or infection |
| ci_agitation | Severe agitation or inability to follow instruction |
| ci_consciousness | Reduced consciousness (GCS below site threshold) |
| ci_ocular_surgery | Recent ocular surgery |

Stop rules (any one → stop the block): nausea, increasing dizziness, pallor/sweating, SSQ above threshold, headache, balance loss, patient asks to stop, therapist judgement, device thermal warning, frame timing above the abort threshold.
