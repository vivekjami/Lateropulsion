# ISO 14971 hazard analysis — baseline (Phase 0 / updated Phase 3 code drop)

Severity: 1 negligible · 2 minor · 3 serious (reversible injury) · 4 critical (irreversible) · 5 catastrophic.
Probability (pre-control): A remote · B occasional · C probable · D frequent. Risk = S × P class; anything ≥ S3·P-C is unacceptable without controls.

Every control must trace to a requirement ID (docs/traceability/requirements.md) and a test. Rows marked **V** need bench/device verification before the pilot.
